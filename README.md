Productivity Pal
Productivity Pal is a personal productivity web app for organizing and tracking daily tasks and goals. Built with vanilla JavaScript, HTML, and CSS, it features task creation, editing, filtering, local storage, and responsive design—ideal for learning advanced JS concepts.

Features
Add, edit, and delete tasks
Mark tasks as complete/incomplete
Filter and search tasks
Persist tasks in local storage
Responsive design for desktop and mobile
